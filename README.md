# Hunter’s Ledger

Простой личный трекер статистики для Hunt: Showdown 1896.

## Что умеет

- Вести игровые сессии и таймер
- Добавлять результаты матчей
- Считать kills, deaths, K/D и combat balance
- Отслеживать прогресс к целевому K/D
- Показывать, сколько матчей примерно нужно до цели
- Показывать примерную дату достижения цели
- Сохранять данные в браузере через `localStorage`

## Данные

Все данные хранятся локально в браузере.

- Прогресс сохраняется после перезагрузки страницы
- Данные не синхронизируются между устройствами
- Очистка данных браузера удалит сохранённую статистику

## Технологии

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages
